# Assignment 3 – CO3: Exception Handling and Multithreading

**Language:** Java  
**Mode:** Pair work (2 students per group)  
**Total marks:** 50  
**Duration:** 1 week

This assignment covers exception hierarchy, checked and unchecked exceptions, try/catch/finally, throw/throws, user-defined exceptions, exception chaining, try-with-resources, debugging, thread life cycle, Thread and Runnable, synchronization, deadlock, inter-thread communication, ExecutorService, Callable, Future and concurrent collections.
