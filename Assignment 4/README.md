# Assignment 4 – CO4: Event-Driven GUI Design

**Course:** Programming in Java (CSA09)  
**Course Outcome:** CO4  
**Total:** 50 marks | **Nature:** Individual  
**Java target:** Java 8 or later (the examples use Java 8-compatible syntax).

## Tasks
1. GUI design review – fee payment, separation of UI and service.
2. Hospital appointment desk – event model, component tree, pseudocode and event trace.
3. Campus library search – nested layout managers and resize behaviour.
4. Event-handling forensics – AWT drawing pad, mouse listener and repainting.
5. Currency converter – frame listener, named inner class, anonymous class and lambda.
6. Campus event registration – layered Swing/JDBC application with MySQL.

## Repository contents
Each Task folder contains a task README and the corresponding starter/solution source files where implementation is required. Add your own execution screenshots under an `output/` folder after running each program.

## Compile and run
Open Command Prompt in the required task folder. For a single source file:
```bash
javac FileName.java
java FileName
```
Task06 additionally requires the MySQL Connector/J driver, a running MySQL server, and the SQL script in `Task06/database.sql`. Add the connector JAR to the classpath.
