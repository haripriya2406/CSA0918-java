# Assignment 1 – Campus Smart-Parking System

Programming in Java, CO1. The PDF contains Tasks 1–12. Initial executable programs are in `Task03` and `Task08`. Other task folders contain tracking READMEs and will be completed as the work progresses.

## Compile and run

Task 3: `cd Task03 && javac ParkingFacility.java && java ParkingFacility`

Task 8: `cd Task08 && javac FeeDemo.java && java FeeDemo`

Use JDK 8 or later. The code is written to be Java 8 compatible.
