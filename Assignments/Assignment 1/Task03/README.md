# Task 3 – Control Logic

Compile and run with `javac ParkingFacility.java` then `java ParkingFacility`.

Expected output:

```text
[0, 0]
[0, 1]
[1, 0]
null
true false false
[0, 1]
```

The program scans a jagged array floor-by-floor, allocates the first free slot and validates indices before releasing an occupied slot.
