# Task 02 – Return by Reference and Its Dangers (4 Marks)

**Context:** Examination Marks Register.

- Implement a function returning a reference to the highest mark in an array so the caller can modify it.
- Demonstrate why returning a reference to a local variable is unsafe and explain the compiler warning and undefined behaviour.
- Compare reference, const reference and copy returns.
- Explain how vector growth can invalidate an earlier reference.
- Show alternative calling code using an index or pointer and compare safety, time and space.

**Files to add:** C++ source file(s), compiler warning evidence, test output/screenshot and explanation.
