# Task 07 – Diagnose, Redesign and Validate (13 Marks)

**Day-4 Design Challenge.** Select one of your Q1–Q6 programs that has a significant limitation as data grows or requirements change.

A. Diagnose the limitation using evidence from the original program.  
B. State a measurable redesign objective.  
C. Explain the revised class/function design, C++ feature used, extra memory and trade-offs; include a class diagram or pseudocode.  
D. Predict the improvement and the measure before implementation.  
E. Implement and validate using the same tests and measurements for original and redesigned versions.  
F. Evaluate whether the objective was achieved, the new costs, and when the original design may still be preferable.

**Files to add:** Original and redesigned C++ source files, diagram/pseudocode, predictions, comparable test/timing evidence, output screenshots and final defence.
